City Care Hospital

Set up using Finder, XAMPP, and your browser. No Terminal commands.

  1. Extract this ZIP. Inside it you will find a folder named citycare.
  2. In Finder choose Go → Go to Folder… and paste /Applications/XAMPP/xamppfiles/htdocs/.
  3. Back up your existing citycare folder by renaming it citycare-backup. Copy the new citycare folder directly into htdocs. Avoid nesting one citycare folder inside another. If you have newer reports or custom database settings, preserve those from your backup.
  4. Open XAMPP Manager and start Apache Web Server and MySQL Database.
  5. If your existing database already works, keep it. For a new installation only, open phpMyAdmin, create/select an empty database named citycare_hospital, and import only citycare/setup-files/citycare_hospital.sql. It includes core, portal, and billing SQL. Do not import it over existing data.
  6. Open http://localhost/citycare/index.php. For a fresh installation, create the first Admin through staff-setup.php, then sign in.

If the page is still blank

Open the browser setup checker. It checks PHP, required extensions, readable files, database connection, and required tables. Send a screenshot of that page if it shows a failed check. No Terminal is needed.

If even the checker cannot open, in Finder select citycare → File → Get Info → Sharing & Permissions. Read access for the local web server is required; the ZIP already provides standard readable file permissions. Also confirm XAMPP Apache is running and you copied the folder to the correct location.

Report uploads

The private_uploads/lab_reports folder must be writable by the account running Apache. The browser checker reports whether it is writable. If it is not, use Finder's Sharing & Permissions or ask your Mac administrator to grant that Apache account write access to this folder only. Folder ownership depends on the Mac and cannot be set universally by a ZIP.

The SQL is assembled from your supplied export. It has no newer portal accounts or records that were not in that export. Keep your working database if you need those existing accounts and records. Payments are recorded manually; no live gateway is connected.
